# Stay Seated

An Android app that tells you whether a movie has a mid-credits or post-credits scene, so you know whether to stay in your seat.

## Install

1. On your Android phone, open the [latest release](../../releases/latest) and download the `.apk` file.
2. Open the downloaded file. If Android asks, allow your browser to install apps.
3. Tap **Install**.

The app checks for updates when it opens. When there's a new version, an **Update** button appears; tap it, then tap **Install**.

## Optional: better answers with a free Gemini key

When the movie database isn't sure, the app can search the web for you using Google's Gemini. Open **Settings**, tap **Get a free key**, create a key, and paste it in. The key is stored only on your phone. Without a key, the app opens a Google search instead.
